🖨️ Printer (fără reclame)

Printare pe imprimante WiFi de birou prin IPP / AirPrint. Fără reclame, fără conturi, fără trafic către servere externe — doar telefonul și imprimanta din rețeaua locală.

Descarcă APK-ul
Instalare
  • Build de debug, rescris la fiecare push pe main.
  • Android cere permisiunea „instalare din surse necunoscute" pentru browser.
  • Semnat cu keystore-ul de debug commitat în repo, deci update-urile se instalează peste versiunea existentă.
  • Necesită Android 7.0 (API 24) sau mai nou.
Diagnostic
  • Două PDF-uri cu aceeași poză, pentru a afla de ce imprimanta refuză imaginile. Descarcă-le și trimite fiecare la print din aplicație, ca PDF.
  • test-app.pdf — scris de generatorul aplicației
  • test-standard.pdf — scris de un generator standard
Ce printează
  • PDF, trimis ca atare
  • Imagini (JPEG/PNG/WebP/HEIF), randate într-un PDF
  • Text și pagini web
